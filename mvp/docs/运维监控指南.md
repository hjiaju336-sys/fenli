# 运维监控指南

## 1. 健康检查端点

服务内置健康检查端点，用于外部监控工具探测服务状态。

- **URL**: `http://162.14.64.4:8777/api/health`
- **正常响应**:
  ```json
  {
    "status": "ok",
    "version": "v0.8.0",
    "uptime": 12345,
    "db": "ok"
  }
  ```
- **降级响应** (数据库不可用但服务仍在运行):
  ```json
  {
    "status": "degraded",
    "version": "v0.8.0",
    "uptime": 12345,
    "db": "error"
  }
  ```

## 2. 服务器自愈机制

服务器上配置了心跳自检脚本，每 1 分钟自动检测服务健康状态。

- **脚本位置**: `~/fenli/heartbeat.sh`
- **cron 配置**: `*/1 * * * * /home/ubuntu/fenli/heartbeat.sh`
- **行为**: 连续 3 次健康检查失败后自动执行 `sudo systemctl restart fenli.service`
- **恢复日志**: `/tmp/fenli_recovery.log`

## 3. 日志持久化

系统日志已配置持久化存储，重启后不会丢失。

- **journald 配置**: `/etc/systemd/journald.conf` 中已添加 `Storage=persistent`
- **日志目录**: `/var/log/fenli/`
- **查看实时日志**: `sudo journalctl -u fenli -f`
- **查看近期日志**: `sudo journalctl -u fenli -n 100`

## 4. UptimeRobot 外部监控

使用 UptimeRobot 免费服务进行外部独立监控。

### 配置步骤

1. 前往 [https://uptimerobot.com](https://uptimerobot.com) 注册免费账号
2. 登录后点击 "Add New Monitor" 添加监控
3. 选择监控类型: **HTTP(s)**
4. 填写监控信息:
   - **Friendly Name**: Fenli 无限流规则怪谈
   - **URL (or IP)**: `http://162.14.64.4:8777/api/health`
   - **Monitoring Interval**: 5 minutes (5 分钟)
5. 配置告警联系人:
   - 推荐使用 **Telegram Bot** 告警: 在 Telegram 中搜索 `@UptimeRobot_bot`，按指引绑定账号
   - 也可选择 **Email** 告警
6. 保存后，UptimeRobot 将每 5 分钟探测一次健康检查端点
7. 当服务不可用时，将通过配置的渠道发送告警通知

### Telegram 告警配置

1. 在 Telegram 中搜索 `@UptimeRobot_bot`
2. 发送 `/start` 开始对话
3. 按 bot 提示绑定你的 UptimeRobot 账号
4. 在 UptimeRobot 控制台的 Alert Contacts 中选择 Telegram 作为通知方式

## 5. 服务器部署清单

首次部署或迁移服务器时，按以下顺序执行：

```bash
# 1. 部署 heartbeat 脚本
scp heartbeat.sh ubuntu@服务器IP:~/fenli/heartbeat.sh
chmod +x ~/fenli/heartbeat.sh

# 2. 配置日志持久化 + cron
bash setup_logging.sh

# 3. 重启服务验证健康检查
sudo systemctl restart fenli.service
curl http://localhost:8777/api/health

# 4. 在 UptimeRobot 添加监控
```

## 6. 手动检查命令速查

| 操作 | 命令 |
|------|------|
| 健康检查 | `curl http://localhost:8777/api/health` |
| 服务状态 | `sudo systemctl status fenli` |
| 重启服务 | `sudo systemctl restart fenli` |
| 查看日志 | `sudo journalctl -u fenli -f` |
| 查看自愈日志 | `cat /tmp/fenli_recovery.log` |
| 查看失败计数 | `cat /tmp/fenli_fail_count` |
| 查看 cron 配置 | `crontab -l` |

### 充值链路设计（$6-$8）

```
用户点击充值 → POST /api/recharge/create(金额)
       → 服务端生成订单号 + 调用支付平台API(虎皮椒/XPay)
       → 返回二维码URL → 前端展示
       → 用户扫码付款 → 支付平台检测到账
       → 回调 POST /api/recharge/callback(订单号+签名)
       → 服务端验签 → 更新订单状态 → 加积分 → 前端弹窗"充值成功"
```

**支付平台选型**（个人开发者可用，无需企业资质）：

| 平台 | 手续费 | 模式 |
|------|------|------|
| 虎皮椒 (Xunhupay) | ~2% | 个人收款码 + 自动回调 |
| XPay | 免费开源 | 自建 + 个人收款码监控 |
| FAST易支付 | 免费开源 | 自建 + WebSocket回调 |

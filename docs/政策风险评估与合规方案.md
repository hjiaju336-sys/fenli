## 二、六大风险及规避方案

### 风险1：恐怖/惊悚内容触碰红线 🔴 高风险

**法规依据**：《网络信息内容生态治理规定》第七条第(五)款——"展现血腥、惊悚、残忍等致人身心不适的"属不良信息。

**本项目的风险点**：
- "血月医院"主题：血月、病房、血迹、尸体、幽灵护士
- "规则怪谈"天然涉及死亡、诡异、超自然
- AI可能生成不可控的恐怖描写

**规避方案**：

| 措施 | 实施 |
|------|------|
| **定位调整** | "规则怪谈"→"**悬疑解谜**"。文案中去掉"恐怖""诡异""怪谈"，替以"悬疑""烧脑""推理" |
| **AI约束** | Pass2 prompt已加入内容约束。增强："禁止描写极端血腥、肢解、虐杀；死亡以暗示方式处理，不过度渲染" |
| **内容警告** | 游戏首页添加："本游戏包含悬疑推理内容，适合16岁以上用户" |
| **用户可选强度** | 提供"轻度悬疑/标准/深度恐怖"三档可选，默认"轻度悬疑" |

### 风险2：封建迷信认定 🔴 高风险

**法规依据**：《规定》第六条第(七)款——"宣扬邪教和封建迷信"属违法信息。

**本项目的风险点**：
- 幽灵角色（护士长王秀兰、保安老周等）
- "夹层空间""月光之力""实验体"超自然设定
- 通灵/幻影/前世记忆等元素

**规避方案**：

- **科学化叙事框架**：所有"超自然"现象都留有科学解释的余地（如RX-77实验药物导致的幻觉、未解的科学现象）
- **标注虚构**：显式标明"本作品为虚构创作，所有人物、事件、设定均为艺术想象"
- **克制用语**：不用"鬼""魂""灵""附体"，改用"残影""意识残留""未解现象"
- **预设模板审查**：6个标准模板确保不触碰红线（已有：血月医院→改为"悬疑医疗"主题）

### 风险3：AI生成内容标识 🟡 中风险

**法规依据**：《人工智能生成合成内容标识办法》（2025年9月1日施行）

**要求**：
- **显式标识**：AI生成文本需在起始/末尾添加提示
- **隐式标识**：文件元数据中嵌入AI生成标记
- 用户协议中明确说明AI生成内容标识方式

**规避方案**：

```
每个AI回复的开头或结尾添加：
「── 以下内容由AI生成 ──」

或在整个聊天界面顶部常驻：
「本游戏剧情由AI实时生成，内容仅为虚构叙事」
```

实施：在Pass2的narrative字段前后自动追加标识文本。

### 风险4：游戏版号问题 🟡 中风险

**法规依据**：《网络出版服务管理规定》

**灰色地带**：
- 互动小说 ≠ 网络游戏（文字类数字作品不需要版号）
- 但如果我们有HP/理智值/装备系统/成就→可能被认定为游戏

**规避方案**：

| 当前特征 | 风险 | 处理 |
|----------|------|------|
| "血量/理智值"数值系统 | 推高游戏认定 | 改为"状态描述"（如"轻微擦伤""精神恍惚"），不显式数值 |
| "通关条件""危险等级" | 推高游戏认定 | 保留但降级为"故事线索"的文案 |
| "规则触发→后果" | 核心玩法，敏感 | 作为叙事机制而非游戏机制呈现 |
| 积分/付费 | 商业化特征 | 定位为"内容付费"而非"游戏充值" |

**最安全定位**：**"AI驱动的互动悬疑小说阅读平台"**——不是游戏，是小说。

### 风险5：个人信息保护 🟢 低风险

**法规依据**：《个人信息保护法》

**当前状态**：
- 仅收集用户名+密码哈希（密码不存明文，SHA256加盐）
- API Key存在用户本地localStorage，服务端不存储
- 无实名认证
- 无手机号/身份证/地址收集

**合规状态**：基本合规。建议添加：
- 隐私政策页面（简单说明收集什么、为什么、如何删除）
- 账号注销功能（一键删除所有数据）

### 风险6：未成年人保护 🟡 中风险

**法规依据**：《未成年人保护法》+ 防沉迷规定

**规避方案**：
- 首页添加年龄确认："本平台内容适合16岁以上用户"
- 不在学校上课时间段（8:00-22:00外）做推送/广告
- 不收集未成年人个人信息
- 内容强度分级（轻度/标准/深度）

## 四、风险总评

| 风险 | 等级 | 规避后等级 | 关键动作 |
|------|------|-----------|----------|
| 血腥/恐怖内容 | 🔴 | 🟡 | AI约束+内容警告+强度可选 |
| 封建迷信 | 🔴 | 🟡 | 科学化叙事+虚构标注+克制用语 |
| AI内容标识 | 🟡 | 🟢 | 显式标识文本+用户协议 |
| 游戏版号 | 🟡 | 🟢 | 定位为"互动小说"非"游戏" |
| 个人信息 | 🟢 | 🟢 | 隐私政策+注销功能 |
| 未成年人 | 🟡 | 🟢 | 年龄确认+内容分级 |

**综合判断**：风险可控。当前产品形态（文字为主、无社交功能、用户自带API Key、自部署）恰好处在监管的**合理灰色地带**。做好内容约束和标识后，合规风险显著降低。

# 功能清单 — AI 无限流规则怪谈游戏

> 日期: 2026-07-20 | 版本: v0.3

---

## 一、已完成的底层能力（✅ 稳定）

### 1. 双 Pass AI 流程
- AI-1: 阅读全量标签 hint → 输出 keep/fetch/drop（标签召回）
- 硬同步: 按 tag_name 查询详情库（确定性 SQL）
- AI-2: 输入用户+上下文+召回详情 → 输出流式叙事 + data_ops(create/update/drop)
- 校验层: tag_name 非空 / category 合法 / tag_detail 非空
- 持久化: create→INSERT, update→UPDATE, drop→前端移除（数据库保留）

### 2. 数据库
- MySQL 8.0, 12 张分表: world/map/rule/character/item/memory × 2 (index+detail)
- save_slots: 存档表（按 player_id 隔离）
- shared_copies: 云端共享副本表
- users: 用户鉴权表
- 所有查询自动带 player_id

### 3. 鉴权系统
- 自实现 JWT（hmac+base64，零依赖）
- /api/auth/register 注册
- /api/auth/login 登录
- HTTP API 通过 Authorization header 鉴权
- WebSocket 通过 query param token 鉴权
- 新用户首次连接自动初始化默认预设

### 4. 存档系统
- 创建存档（API + 前端按钮）
- 列表（按 player_id 隔离）
- 删除（带确认）
- 下载为 JSON
- 上传 JSON 导入
- 自动清理（保留最近 10 个）
- save_type 区分游戏存档 / 预设模板

### 5. 模板系统
- 标准模板: 6 个 JSON 文件（血月医院/午夜列车/深渊水族馆/钟摆学院/镜面迷宫/迷雾之城）
- 云端共享: shared_copies 表，上传/列表/下载计数/加载
- 用户模板: save_slots 中 save_type='preset' 的条目
- 加载预设清空当前数据 → 写入新数据

### 6. AI Provider
- 支持 Anthropic / OpenAI / DeepSeek
- 用户自带 API Key（localStorage 存储，随请求透传）
- 模型可下拉选择 + 手动输入 + 拉取 API 模型列表

### 8. WebSocket 消息协议

| 方向 | type | 内容 |
|------|------|------|
| 前端→后端 | user_turn | userInput, apiKey, model |
| 前端→后端 | cancel | 中断当前生成 |
| 后端→前端 | init_state | hotTags, hotMemories, player_detail, world_intro, world_name, world_desc |

| 后端→前端 | turn_complete | hotTags, player_detail, created/updated/dropped, tokens, latency |
| 后端→前端 | error | message |
| 后端→前端 | cancelled | 中断确认 |

## 二、前端页面结构

### 页面清单
1. **登录页** — 账号/密码/确认登录/点击注册
2. **首页** — 快速开始/继续游戏/模板管理/系统设置
3. **模板页** — 标准模板区/云端共享区/自建模板区 + 新建模板 + 返回
4. **编辑器** — 5 步向导: 世界→地图→规则→角色→物品
5. **检查保存页** — 预设名称/简介/保存到服务器/本地/上传云端
6. **游戏主界面** — 世界卡片/角色状态/聊天区/输入栏/按钮栏
7. **调试面板** — 库统计/分类标签/玩家状态

### 弹窗
- API 配置弹窗（密钥隐码+显隐切换+模型拉取）
- 自定义确认弹窗（羊皮卷风格，替换浏览器 alert/confirm）
- 自定义提示弹窗
- 存档管理弹窗（列表/加载/删除/导入）

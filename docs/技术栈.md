# 技术栈文档 — AI 无限流规则怪谈游戏

> **项目名:** fenli | **版本:** v0.3 MVP | **日期:** 2026-07-20

---

## 后端

| 层 | 技术 | 用途 |
|------|------|------|
| 语言 | **Python 3.14** | 主要开发语言 |
| Web 框架 | **FastAPI** | HTTP API + WebSocket，原生异步 |
| ASGI 服务器 | **Uvicorn** | 运行 FastAPI 应用 |
| ORM | **SQLAlchemy 2.0** | 数据库建模与查询 |
| 数据库驱动 | **PyMySQL** | Python ↔ MySQL 连接 |
| 数据库 | **MySQL 8.0** | 12 张分库表 + 用户表 + 存档表 |
| AI 调用 | **httpx** (AsyncClient) | 直接 HTTP 调用 Anthropic/OpenAI/DeepSeek API |
| 认证 | **自实现 JWT** (hmac + base64) | 零依赖，Python 内置库 |
| 数据校验 | **Pydantic v2** | 请求体校验、AI 输出格式定义 |

## 前端

| 层 | 技术 | 用途 |
|------|------|------|
| 语言 | **Vanilla JavaScript (ES6)** | 无框架，原生 DOM 操作 |
| 样式 | **CSS3** (CSS Variables + Flexbox + Gradient) | 羊皮卷/血橙金主题 |
| 通信 | **WebSocket** (原生) | 流式剧情推送 |
| 通信 | **fetch API** | HTTP REST 请求 |
| 持久化 | **localStorage** | API Key、登录态、预设草稿 |
| 模板 | 静态 HTML 单文件 | 9 个页面模块 |

## 未使用（有意避开的）

| 技术 | 原因 |
|------|------|
| LangChain / Dify | 流程是自定义有状态编排，非标准 RAG 链 |
| React / Vue | MVP 阶段用原生 JS 更快 |
| aiomysql | pip 代理限制，改用同步 PyMySQL |
| pyjwt | 代理限制，改用内置 hmac 实现 |
| Docker | 尚未容器化（用户本地 MySQL 直接连接） |

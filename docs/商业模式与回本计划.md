# 商业模式 — Steam创意工坊模型

> 核心：模板免费玩 + 自愿打赏 + 平台抽成 + 竞价推广

## 一、Steam创意工坊怎么赚钱？

Steam不直接从工坊赚钱。它赚的是：**工坊→更多用户→更多游戏购买→平台抽30%。**

我们不一样——我们没有"游戏本体"可以卖。但我们可以借鉴另一个模型：

## 二、Bandcamp/"pay what you want" 模型

```
模板免费下载 → 玩家玩完 → 觉得好 → 自愿打赏
                                    ↓
                            创作者收70% + 平台收30%
```

**关键**：不打赏也能玩。不打赏不丢人。打赏是因为真的觉得好。

ACG社区天然适合这个模型——"为爱发电"+"为爱付费"是核心文化。同人展上卖本子也是这个逻辑：你先翻、觉得好、再买。

## 三、具体设计

### 模板页面的"支持创作者"按钮

```
┌─────────────────────────────┐
│  血月医院                     │
│  by 创作者A                   │
│  ★★★★☆ 4.2 (128评)          │
│  👁 3.2k次游玩                │
│                             │
│  [开始游戏]（免费）            │
│                             │
│  ❤️ 支持创作者                │
│  ┌──────────┬──────────┐    │
│  │ ¥3 投币  │ ¥8 赞赏  │    │
│  │ (100积分) │ (300积分) │    │
│  └──────────┴──────────┘    │
│  已有 47 人支持，累计 ¥386    │
└─────────────────────────────┘
```

### 规则

| 项目 | 说明 |
|------|------|
| 游玩 | 永久免费，1积分门槛（等于免费） |
| 打赏 | 纯自愿。金额可选¥3/¥8/¥15/自定义 |
| 分成 | **创作者70% / 平台30%**（对标Steam的75/25，App Store的70/30） |
| 结算 | 满¥50可提现（微信/支付宝） |
| 排行 | "本月最受支持创作者"排行榜（首页展示） |

### 为什么有人愿意打赏？

1. **玩了几十小时的通关副本**——创作者花几天设计的世界，打赏¥8合理
2. **社群认同**——"这个副本47人支持过了，我支持一下"
3. **鼓励续作**——"希望作者继续做更多副本"
4. **ACG"为爱发电"传统**——同人展买本子、B站充电、爱发电赞助，用户习惯已有

### 平台怎么赚？

| 来源 | 计算 | 100模板×平均支持¥5×10人次 |
|------|------|--------------------------|
| 打赏抽成30% | ¥5×30% = ¥1.5/次 | 100×10×¥1.5 = **¥1500** |
| 积分包差价 | 打赏用积分→积分包有毛利 | +¥300-500 |
| 月卡 | 独立收入 | +¥300-500 |
| 竞价推广 | 创作者投积分买首页推荐位 | +¥100-300 |
| **合计** | | **¥2200-2800/月** |

### 竞价推广（不破坏公平性）

```
首页"推荐模板"位 → 不是编辑精选，是创作者用积分竞价的
  → 创作者A投500积分 → 排第1位（本周）
  → 创作者B投300积分 → 排第2位
  → 积分来自他们自己获得的打赏 → 生态内循环
```

平台收的是"积分消耗"——创作者投积分买推广→积分被消耗→减少平台积分通胀压力。

## 四、与月卡的关系

| 用户类型 | 花钱方式 |
|----------|----------|
| 纯玩家（轻度） | 偶尔打赏喜欢的模板 ¥3-5 |
| 纯玩家（重度） | 月卡 ¥22 + 频繁打赏 ¥5-15 |
| 创作者（轻度） | 赚积分→换月卡（等于免费会员） |
| 创作者（重度） | 赚积分→提现 ¥50-500/月 |

**创作者用积分换月卡=零成本会员=平台零成本用户增长。**

## 五、为什么比"模板付费解锁"好

| | 付费解锁 | 自愿打赏 |
|------|---------|----------|
| 新用户感知 | "什么都要钱" | "全是免费的" |
| 创作者 | 定价压力（定高了没人买） | 无压力（免费提供，意外之喜） |
| 平台 | 需要审核定价合理性 | 纯市场行为，无需审核 |
| 传播 | 阻碍传播（"收费的，不玩了"） | 加速传播（"免费的！"） |
| 收入 | 确定但不稳定 | 不确定但可能爆发 |
| 社区氛围 | 交易型 | 互助型 |

**ACG社区天然排斥"交易型"关系。** 同人展上你说"先付钱再看"没人理你，但你说"随便翻，喜欢再买"反而卖得更好。

## 六、一句话

**模板永远免费。喜欢就投币。创作者拿70%，平台拿30%。好内容自然赚钱。**

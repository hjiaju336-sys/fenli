# 角色羁绊系统设计

> 日期: 2026-07-24 | 目标: 重构角色数据结构与展现形式，支撑类乙游的角色魅力体验

## 一、数据结构重构

### 1.1 当前结构（v0.5）

```json
{
  "tag_name": "护士长王秀兰",
```

### 1.3 字段说明

#### 视觉呈现
| 字段 | 类型 | 说明 |
|------|------|------|
| 立绘 | string | 角色默认展示图URL |
| 立绘表情 | dict | 不同情绪对应的立绘变体，AI根据上下文选择 |
| 主题色 | string | 角色代表色，用于UI卡片镶边/对话框染色 |
| 角色标签 | array | 简短关键词，展示在角色卡上 |

#### 性格设定
| 字段 | 类型 | 说明 |
|------|------|------|
| 性格 | dict | 大五人格（OCEAN）1-10评分，AI据此生成对话 |
| 说话风格 | string | 自然语言描述，直接注入AI的system prompt |
| 口头禅 | array | 角色标志性话语 |
| 不会说的话 | array | 防止AI OOC的约束 |
| 秘密 | string | 角色隐藏信息（剧透） |
| 恐惧 | string | 角色深层恐惧 |
| 渴望 | string | 角色核心动机 |

#### 关系与羁绊
| 字段 | 类型 | 说明 |
|------|------|------|
| 好感度 | int | 0-100，影响角色对玩家的友好程度 |
| 信任度 | int | 0-100，影响角色是否分享秘密/给予关键物品 |
| 依赖度 | int | 0-100，玩家帮助角色越多越高，高时角色主动提供帮助 |
| 态度描述 | string | AI用于生成对话的态度基调 |
| 态度演变 | dict | 不同好感/信任阈值下的行为变化，直接注入Pass2 prompt |
| 对其他角色态度 | dict | 角色间关系网，丰富群像互动 |

#### 互动记忆
| 字段 | 类型 | 说明 |
|------|------|------|
| 互动记录 | array | 关键互动事件日志，精简到3-5条最重要的 |
| 玩家知晓的秘密 | array | 玩家已解锁的角色隐藏信息 |
| 角色状态 | string | 活跃/退场/转变 |
| 可能退场条件 | string | 角色故事线的终点 |

## 二、前端展现形式

### 2.1 游戏界面：侧栏角色卡升级

```
┌──────────────────────┐
│  ◉ 王秀兰             │  ← 角色名 + 状态指示灯
│  ┌──────────────────┐ │
│  │   [立绘缩略图]    │ │  ← 40x40圆形头像
│  └──────────────────┘ │
│  「还有人需要我…」     │  ← 角色当前台词(动态)
│  信任: ████░░ 40%     │  ← 仅剧透模式显示数值
│  ─────────────────── │
│  标签: #引导者 #赎罪者  │
│  持有: 📓日记本 🔑铜钥匙│
│  ─────────────────── │
│  [💬 对话] [🔍 观察]   │  ← 快捷操作按钮
└──────────────────────┘
```

### 2.3 对话界面：角色出场特效

当角色在AI叙事中登场时，聊天区展示角色出场卡：

```
┌──────────────────────────────┐
│                              │
│        [立绘居中大图]          │
│                              │
│     王 秀 兰                  │
│     〝还有人需要我…〞          │
│     护士站的幽灵护士长         │
│                              │
│  [渐变消失，过渡到对话文本]     │
└──────────────────────────────┘
```

这个出场卡只在角色**首次登场**或**关键剧情节点**（如好感突破阈值、角色态度重大转变）时展示。

### 2.4 角色关系图谱（新功能）

在变量面板新增"关系"子标签，展示当前副本角色间的关系：

```
┌─────────────────────────┐
│  角色关系               │
│                         │
│      王秀兰 ──愧疚──→ 赵明│
│         │               │
│       恐惧+愤怒          │
│         ↓               │
│       张德胜 ←──鄙视── 老周│
│                         │
│  你 ←──友善── 王秀兰     │
│  你 ←──信任── 赵明       │
│  你 ←──警惕── 老周       │
└─────────────────────────┘
```

纯CSS+SVG实现，不需要mermaid等库。关系线颜色代表关系性质（绿=正面/红=负面/灰=中立）。

### 2.5 角色状态变化提示

当角色好感/信任度发生显著变化时，聊天区插入一条特殊的系统消息：

```
─────────────────────────────
  王秀兰 对你的 信任 提升了
  「看来…你和那些人不一样」
  ████░░░░░░ 40 → ██████░░░░ 60
─────────────────────────────
```

用角色主题色作为边框色，配对应表情的立绘缩略图。

## 三、AI Prompt 集成

### 3.1 Pass2 Prompt 中注入角色信息

当前Pass2的world_context已经有了角色详情（通过hard_sync格式化）。优化方向：

**在角色详情中优先展示**：
```
─── 角色：王秀兰 ───
性格: 温柔但时常陷入回忆… (5维度评分在提示词中转为自然语言)
态度: 友善但有所保留——她见过太多人没能活着离开
好感度: 65 (高) → 她会主动提供帮助
信任度: 40 (中) → 她还不会说出最大的秘密
互动记忆:
  - 第3轮: 玩家帮她找回护士帽 → 态度积极
  - 第7轮: 玩家拒绝她的警告 → 略有失望
说话风格约束:
  ✓ 对年轻病人使用「孩子」称呼
  ✓ 提到张德胜时语调变冷
  ✗ 绝不说: 「张德胜是对的」「我不在乎病人」
```

### 3.2 AI根据好感度调整角色行为

在Pass2的system prompt中增加：
```
## 角色行为受好感度/信任度影响
- 好感度>60: 角色主动提供帮助、透露额外信息、给予非关键物品
- 好感度<30: 角色回避互动、给出警告而非帮助、可能设下障碍
- 信任度>70: 角色分享秘密、给予关键物品/线索
- 信任度<20: 角色可能说谎、隐瞒关键信息
- 依赖度>50: 角色在危险时向玩家求助（触发支线剧情）
```

## 五、兼容性说明

新字段全部使用 `.get()` 回退模式：
- 如果tag_detail中有新字段（立绘/性格/态度演变等）→ 使用
- 如果没有（旧数据）→ 回退到基础行为，不崩溃
- 旧的"外貌"/"行为逻辑"/"当前意图"字段保留，作为fallback

这保证了现有6个preset模板不需要立即更新，渐进式迁移。

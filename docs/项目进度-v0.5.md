## 三、v0.5.2 新增Bug修复

| Bug | 根因 | 修复 |
|-----|------|------|
| orchestrator NoneType崩溃 | pass1/pass2中str.join收到None元素 | 全部join改为`str(x) for x in ... if x is not None` |
| 404 /undefined | _DEF_AVATAR_PLAYER在IIFE之后赋值→getPlayerAvatar()返回undefined→img src="/undefined" | 常量定义移到IIFE之前 + img空src改为data:, |
| ERR_UNKNOWN_URL_SCHEME | `<link href="about:blank">` 触发浏览器加载非法协议 | 改为`data:text/css,` |
| like API 500 | `/like/{id}`路由被`/{type}/{id}`泛匹配拦截→空body解析失败 | like/report端点移到泛匹配之前 |
| 管理面板积分显示undefined | SQL未LEFT JOIN point_accounts | 添加COALESCE + 前端安全回退 |
| 注册积分只有100 | system_config默认值错误 | 改为99999 |
| 兑换码格式错误 | 无HMAC签名/无FL-前缀 | HMAC-SHA256 + base32 + FL-XXXX-XXXX-XXXX |
| ban端点逻辑错误 | 操作is_admin字段而非is_banned | 新增is_banned字段 + ban端点修正 |

## 四、新增功能详情

### 4.1 可配置N值系统
- 游戏输入栏左侧N值选择器（N3/N5/N7/N10/N15/N20）
- 控制：上下文窗口（N×2条消息）/ 总结触发频率 / 回滚范围
- localStorage持久化，WS透传

### 4.2 消息编辑
- 每条用户消息悬停显示✎按钮
- 点击→textarea编辑→确认→用新内容重新发送给AI
- AI基于修改后的消息生成新回复

### 4.3 逐条回滚
- 每条用户消息悬停显示↩按钮
- 点击→确认弹窗→调用POST /api/rollback/{turn}
- 服务端查找最近存档→清空当前数据→恢复存档

### 4.4 聊天历史存档
- doSave()将DOM中所有消息序列化存入save_data.recent_messages
- 加载存档时window._savedMessages → init_state渲染→恢复完整聊天记录
- 恢复的消息自动附加✎/↩按钮

### 4.5 提示词优化
- Pass1: "精准优先" + 记忆limit 3-8条 + 关键词匹配引导
- Pass2: 叙事200-500字 + 字段规范压缩 + 记忆自然融入
- Summary: 50-150字/条 + [事件]→[结果]格式 + 去重 + 专有名词保留

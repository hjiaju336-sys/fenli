## 商业模式：积分转卖 + 月卡双轨

### 单元经济学

**单轮 API 成本**（DeepSeek V4 Flash，双 Pass 架构）：
- 平时：~0.014 元/轮
- 高峰：~0.028 元/轮
- 加权平均：~0.018 元/轮

**积分包利润空间**：

| 积分包 | 价格 | 可玩轮数 | API 成本 | 毛利 | 毛利率 |
|--------|------|----------|----------|------|--------|
| 1000 积分 | ¥6 | 200 轮 | ¥3.60 | ¥2.40 | 40% |
| 5000 积分 | ¥30 | 1000 轮 | ¥18.00 | ¥12.00 | 40% |
| 20000 积分 | ¥98 | 4000 轮 | ¥72.00 | ¥26.00 | 27% |

**月卡**：本质是锁定用户+平滑现金流的工具，不是独立盈利产品。真正利润在积分包。

---

## 两种模式对比：用户自带 Key vs 平台承担成本

| 维度 | 用户自带 Key（老架构） | 平台承担成本（新架构） |
|------|----------------------|----------------------|
| 用户体验 | 需注册 API 服务、获取 Key——门槛极高 | 注册即玩，零配置 |
| 变现方式 | 仅自愿打赏，不可预测 | 积分包 + 月卡，可预测 |
| 平台收入 | 打赏抽成 30% | 积分包毛利率 27-40% |
| 用户增长 | 高门槛过滤大量用户 | 200 积分/40 轮免费体验 |
| 结论 | 是工具 | **是产品** |

---

## 最大的 3 个机会

1. **三空白交叉点**：规则怪谈 x AI x 女性向，目前没有直接竞品
2. **UGC 创作者经济**：模板编辑器 + 云端共享 + 70/30 分成 = 唯一护城河
3. **零边际成本规模化**：每增一个用户，服务端成本近乎零

---

## 最大的 3 个风险

1. **政策监管**：AI 生成内容 + 规则怪谈（恐怖/悬疑）= 三重敏感叠加。Glow 已被下线
2. **变现滞后**：v0.7.0 已部署但充值链路未接入，服务器在"只出不进"
3. **单人运营天花板**：>500 用户时服务质量断崖下降

---

## 未来 3 个月最该做的 3 件事

1. **接入支付**（第 1-2 周）——最高优先级
2. **获取 100 个种子用户**（第 1-4 周）——验证留存
3. **启动创作者经济**（第 4-12 周）——让 UGC 飞轮转起来

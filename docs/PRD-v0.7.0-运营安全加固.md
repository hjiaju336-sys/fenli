# PRD：v0.7.0 防白嫖 + 运营安全加固

> 版本：v1.0 | 日期：2026-07-30 | 状态：待老板审核 | PM 签字：PM 暂代 🐾

## 1. 背景

安全审计发现 12 个运营风险，其中 4 个 P0 级别可造成直接经济损失（API 被无限代理、积分被刷、封禁无效、存储被撑爆）。

## 2. 核心目标

部署到服务器后，不能被人白嫖 API 费用、不能被人刷积分、不能被人搞崩服务。

## 3. 功能范围

### P0 — 上线前必须修

#### F1：注册积分默认值 + 注册频率限制 🔴
- `system_config` 的 `register_bonus` 默认值 99999 → 200（够体验 40 轮）
- 新增 IP 级注册频率限制：每 IP 每小时最多 3 个注册
- 新增全局注册速率限制：每分钟最多 10 个注册
- 位置：`server.py` register 端点 + `db.py` 新增 `_check_rate_limit()` 工具函数

#### F7：管理员系统配置面板 🔴
- 管理面板新增"系统配置"Tab，可在线修改 `system_config` 表的所有配置项
- 配置项包括：
  | 配置键 | 说明 | 默认值 |
  |------|------|------|
  | `register_bonus` | 注册赠送积分 | 200 |
  | `turn_cost` | 每轮对话消耗积分 | 5 |
  | `sign_in_max` | 签到每日最高积分 | 100 |
  | `rate_limit_user_per_min` | 每用户每分钟最大对话轮数 | 6 |
  | `rate_limit_ws_per_ip` | 每 IP 最大 WebSocket 并发数 | 5 |
  | `rate_limit_register_per_hour` | 每 IP 每小时最大注册数 | 3 |
  | `save_max_size_kb` | 存档最大大小(KB) | 500 |
  | `ws_idle_timeout_min` | WebSocket 空闲超时(分钟) | 5 |
- 管理员修改后即时生效（下次请求生效，无需重启）
- 前端：`page-admin` 新增"系统配置"tab，表单式编辑 + 保存按钮

#### F2：封禁功能生效 🔴
- `_pid()` 函数增加 `is_banned` 检查
- WebSocket handler 在 token 验证后增加 banned 检查
- `/api/auth/login` 增加 banned 检查
- 被封禁用户看到"账号已被封禁"提示

#### F3：API 对话速率限制 🔴
- 每用户每分钟最多 6 轮对话（10 秒冷却）
- 每 IP 最多 5 个并发 WebSocket 连接
- 超限返回友好提示"请稍后再试"而非直接断开

#### F4：存档/云端副本大小限制 🔴
- `create_save` 和 `upload_copy` 增加 500KB 上限检查
- 超限返回 400 "数据过大"

### P1 — 本周修

#### F5：评论/建议/举报频率限制
- 评论：每用户每小时 10 条
- 建议：每用户每天 5 条
- 举报：`(comment_id, reporter_id)` 唯一约束防重复

#### F6：全站基础速率限制
- 登录：每 IP 每分钟 20 次
- 签到：已有每日限制 ✅

### P2 — 后续

- 验证码（Cloudflare Turnstile）
- 密码 bcrypt 升级
- 内容审核接入
- WebSocket 空闲超时断开（5 分钟）

## 4. 风险

| 风险 | 缓解 |
|------|------|
| 速率限制影响正常用户体验 | 阈值设得宽松（6 轮/分钟足够手动输入） |
| IP 限制在 NAT/共享网络下误伤 | 检测 X-Forwarded-For header，且阈值设得够高 |
| 内存存储限制计数器重启丢失 | 可接受——重启后计数器清零，服务恢复即可 |

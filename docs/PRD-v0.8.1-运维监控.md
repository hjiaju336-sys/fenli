# PRD：v0.8.1 运维监控接入

> 版本：v1.0 | 日期：2026-07-31 | 状态：待老板审核 | PM 签字：PM 暂代 🐾

## 1. 背景

网站挂了我们完全不知道——上次旧进程从 7/30 到 7/31 一直占着端口，systemd 失败 268 次，没人发现。

## 2. 核心目标

| 目标 | 标准 |
|------|------|
| 挂掉能感知 | 站点不可用时 5 分钟内收到通知 |
| 知道为什么挂 | 能快速看到最近的日志+错误 |
| 低成本 | 免费方案优先 |

## 3. 功能范围

### F1：健康检查端点 🔴
- 新增 `GET /api/health` 端点，返回 `{"status":"ok","version":"v0.8.0","uptime":12345,"db":"ok"}`
- 检查 MySQL 连接是否正常
- 无需鉴权

### F2：Uptime 监控 🔴
- 接入免费外部监控服务，每 5 分钟探测一次
- 推荐：**UptimeRobot**（免费 50 个监控，5 分钟间隔）
- 或：**Better Uptime**（免费 10 个监控，3 分钟间隔，含心跳）
- 挂掉时通过 Telegram/微信/邮件通知老板

### F3：server 日志优化 🟡
- systemd journal 日志改为持久化存储（默认重启丢失）
- 关键错误打标签便于搜索

### F4：心跳 cron 🟡
- 服务器本地每 1 分钟自检一次
- 连续 3 次失败 → 自动 `systemctl restart`
- 避免挂一天没人知道

## 4. 不在本次范围
- Grafana/Prometheus 重型监控
- 性能指标采集
- APM 接入

## 5. 风险
- 外部监控需服务器有公网 IP（已有 ✅）
